# 需求与物理设置门

## 先区分问题类型

在修改工程前明确属于哪一种：

- 无限周期单元：关注单元周期、入射角、Floquet 模式、反射/透射幅相和极化转换；
- 有限超表面或阵列：关注有限口径、边缘效应、馈源或 Plane Wave、RCS/远场和阵列结果；
- 反射阵列或透射阵列：还要明确馈源位置、单元相位分布、口径和量化方式；
- 吸波或频率选择表面：明确反射、透射、吸收及带宽定义。

类型不清楚会直接改变边界、激励和结果含义，必须先检查工程或询问用户。

## 人机分工与任务边界

| 角色 | 负责内容 |
| --- | --- |
| 人类用户 | 应用目标、主要物理机制和单元拓扑、材料与制造约束、指标权重、参数硬边界、预算、停止条件和最终验收 |
| Agent | 整理缺失信息、审计当前工程、提出有限数量的候选建议、说明依据/假设/权衡，并草拟可调参数和执行计划 |
| MCP / Runtime | 读取工程，按已批准模板完成重复建模，在批准范围内执行扫参或优化，并返回结构化证据 |

Agent 可以在不修改工程的情况下给出带假设的候选建议，但建议应按“建议—依据—假设—权衡—需用户决定—可委托动作”组织。任何写工程、启动仿真、扫参或优化之前，都要形成用户认可的任务边界；缺少用户选择不等于允许 Agent 代选总体方案。

## 必须明确的信息

- 坐标系、长度单位、频率单位和传播方向；
- 工作频段、目标频点和允许带宽；
- 入射角、方位角、极化基底和目标极化；
- 周期、单元尺寸、层叠顺序、基板厚度、金属厚度和空气区域；
- 材料的介电常数、损耗角、导电率及其证据来源；
- 目标量：复数 S 参数、反射/透射相位、吸收率、极化转换率、RCS、增益或场分布；
- 可调参数、取值范围、制造约束和验收条件。

## 工程检查门

对已有工程先只读检查：

- 参数表及参数描述；
- 实体、组件、材料和层叠；
- 六面边界、Floquet 端口或 Plane Wave；
- 求解器、频率范围、监视器和已有结果节点；
- 当前工程路径、锁状态以及是否为工作副本。

无法通过工具读取的字段要标为未知，不得用常见模板补全。

## 求解前物理门

- 周期方向及相位关系与实际结构一致；
- Floquet 端口位于正确的 Z 面，模式数量覆盖目标同极化和交叉极化分量；
- Plane Wave 的传播方向和电场极化与坐标定义一致；
- 背景、开放边界和空气距离符合目标问题；
- 最小缝隙、薄金属、过孔和高场区域有相应网格策略；
- 频率范围和监视器覆盖验收指标。

任一关键条件仅为猜测时，先停止并报告缺失信息。

本检查门用于帮助用户准备和审查超表面单元任务，不承担完整器件系统综合、制造签核或最终方案批准。若用户进一步委托有限口径、阵列映射或其他系统级工作，应单独明确范围、工具能力和人工验收点。
