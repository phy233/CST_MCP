# 仿真与结果验证

## 周期单元

无限周期单元通常使用 Unit Cell/Periodic 边界与 Floquet 端口。解释结果前确认：

- Zmin/Zmax 端口、传播方向和参考面；
- 模式顺序、极化基底和同/交极化映射；
- Run ID、频率网格和参数组合；
- 数据是复数幅值、线性幅度、功率还是 dB。

常用派生量必须写明定义，例如：

- 反射率 `R = |S_reflect|^2`；
- 透射率 `T = |S_transmit|^2`；
- 无其他传播通道且归一化成立时，吸收率可按 `A = 1 - R - T` 估算；
- 极化转换率需要明确分子、分母和采用的 Floquet 模式。

存在高阶传播模式、损耗、非正交归一化或多端口时，不能机械套用简化能量公式。

## 有限结构

Plane Wave 激励的有限结构通常检查散射、RCS、近场或远场。普通 Plane Wave 不应被描述成能够直接生成普通端口 S 参数。若任务需要端口 S 参数，应先确认存在实际端口或改用适当周期单元方案。

## 成功判据

- 求解器启动返回值和停止状态合理；
- 等待期间新增日志没有 CST `*** Error ***` 块；
- 出现新的目标 Run ID 或结果节点；
- 导出数据非空、频率严格递增、单位和 quantity 明确；
- 对比的多个结果来自相同频率网格、端口/模式定义和工程版本；
- 结果满足基本物理约束，异常值已解释。

只得到旧结果、空文件、缺失 Run ID 或无法确认极化映射时，将结果标为未验证，不得据此给出优化成功结论。

## 每轮报告

报告工程版本、参数、Run ID、结果树路径或文件路径、计算公式、指标值、异常日志、是否通过验收以及下一步只修改哪个因素。
