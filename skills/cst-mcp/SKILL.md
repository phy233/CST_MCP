# CST MCP Skill

本 Skill 负责 MCP 工具调用边界，不替用户完成总体电磁设计。Agent 可以提出建议并执行用户已经确认的操作；工程目标、关键物理选择、参数硬边界、计算预算和最终结论由用户决定。接入 CST 不等于具备端到端或全自动设计能力。

超表面的设计辅助由 `cst-metasurface-design` 负责；参数优化和受控扫参由 `cst-runtime-optimization` 负责。

输入应包含具体工程或运行记录、目标动作和授权范围；沿用对话中已明确的信息，只补问影响执行的缺项。没有可用的 CST MCP 连接时，说明缺失的执行接口，需要 CLI 时路由到 `cst-runtime-cli`。

## 调用原则

- 直接使用 MCP 当前暴露的工具；工具名称、描述和输入 Schema 是调用事实来源，不在文档中维护固定工具数量。
- 使用用户指定的绝对 `project_path`。多个打开工程、目标身份不唯一或锁未释放时，停止写入和关闭操作。
- 对未知工程先调用只读检查工具，整理参数、实体、端口、边界、监视器和结果节点，再把建议、依据、假设和待用户决定项分开报告。
- 默认逐步调用原子工具。只有用户明确选择时才使用管道，并先展示展开步骤、输入和停止条件。
- 每次调用先检查 `terminal` 和 `await_user_decision`，再判断 `status`、`error_type`、`message` 和关键输出，不以进程退出码或传输成功代替业务成功。
- 用户批准重复建模模板或优化任务卡后，可以在已批准的对象、范围、预算和停止条件内连续执行；改变拓扑、目标、硬边界、预算或工程路径时重新交给用户决定。

## 成功信任与必要检查

公开 MCP 工具没有返回错误并给出结构化成功状态时，充分相信 CST 已成功执行对应 VBA。不要为了再次证明执行成功，在普通参数、材料、几何、布尔、边界、端口、监视器或求解器配置调用前后重复查询参数、实体树、配置 getter 或 History diff。

只有以下边界保留必要检查：

- 初始信息确实未知且无法构造正确请求，或目标工程身份不唯一时，先做一次只读确认；
- 结果导出、截图或其他文件产物，检查工具承诺的文件存在且非空；
- 异步求解需要等待完成，并在使用结果前取得对应 Run ID 或结果数据；
- 接口明确返回错误、超时、transport error 或状态 ambiguous 时，先判断实际副作用再决定是否重试；
- 删除、覆盖、关闭或进程终止前确认目标与用户授权；这是权限控制，不是重复验证 VBA。

成功执行 VBA 与科学结论正确是两个层次。可以报告操作已成功执行，但单元方案、物理解释和指标是否成立仍以结果与用户审查为准。

## 终止与失败处理

- 返回 `terminal=true` 或 `await_user_decision=true` 时，立即停止本回合对该任务的后续 CST 调用，包括查询、轮询和重试。报告返回的 `timeout_class`、`solver_left_running` 和恢复建议；按返回的 `recovery` 等待用户决定恢复时机。`long_run_relinquish` 表示让出等待，不等于求解失败或求解器已停止。
- 只有未触发上述终止分支时，写操作返回超时、Worker 退出或 transport error 才进入副作用检查；不立即重试，先检查 History、目标工程和实际副作用。
- expected-before 表示未应用，仍需用户确认后才能重试；expected-after 表示已应用并应跳过；两者都不匹配时按 ambiguous 停止。
- 不因工具重新连接成功而重复建模、启动求解或覆盖工程。
- 未收到终止信号的异步仿真使用等待或状态工具，不反复发送启动命令。

## 记录与恢复

- MCP 自动记录工具请求、参数、返回值、耗时和可关联的 History 快照。
- 设计假设、用户确认和人工处置通过 MCP 工具 `record-agent-note` 显式记录。
- 查询一次调用的 History 变化使用 MCP 工具 `inspect-interaction-history`。
- 创建物理检查点、重放副本和人工 reconciliation 属于高风险 CLI 运维操作，MCP Agent 不自行绕过暴露策略。

需要详细的 History、检查点和交互审计步骤时，路由到 `cst-runtime-cli`，由该 Skill 按需读取自身的 `history-and-recovery.md`。如果 `cst-runtime-cli` 未安装，停止高风险恢复操作并说明依赖缺失，不使用脆弱的兄弟目录相对路径。需要超表面设计判断时，使用 `cst-metasurface-design`。

完成或暂停时，报告目标工程、实际动作、接口状态、结果或日志位置和未完成事项；只对必要产物提供验证证据。
